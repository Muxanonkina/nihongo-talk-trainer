🔹 Frontend

Цель: интерфейс для пользователей, запись и воспроизведение речи, мультиязычность.

Основные задачи:

UI/UX интерфейс
Экран диалога
Кнопка записи и управление аудио
Проигрывание аудио
Мультиязычный интерфейс (i18n)
История обучения, оценки, повтор диалогов
Технологии (рекомендуется):

React / Next.js
TypeScript
Tailwind CSS
Web Speech API (запись голоса)
i18n библиотеки (react-i18next или аналог)

Примечания:
Разделять компоненты на переиспользуемые блоки (DialogScreen, History, AudioPlayer)
Использовать Context API или Zustand/Redux для глобального состояния

🔹 Backend

Цель: управление пользователями, хранение данных, логика диалогов, API для AI.

Основные задачи:

Авторизация и аутентификация (JWT)
CRUD пользователей
Хранение прогресса и статистики
Управление сценариями диалогов
API для AI (оценка, генерация диалогов)
Технологии:

Node.js + Express / NestJS
Prisma ORM
PostgreSQL
JWT для авторизации
(Опционально) Swagger для документации API

Примечания:
Разделить слои: Controllers / Services / Repositories
Сделать отдельные роуты для диалогов, пользователей и AI


🔹 AI / Speech

Цель: распознавание речи, озвучка, оценка произношения, генерация диалогов.

Основные задачи:

Speech-to-Text (распознавание речи)
Text-to-Speech (озвучка)
Оценка произношения
Генерация диалогов
Технологии / варианты:
OpenAI Whisper (STT)
Google Speech API
Azure Speech
GPT (оценка ответа и генерация диалогов)

Примечания:
Логику AI отделить через отдельный слой/сервис на backend
STT и TTS могут работать прямо с frontend через Web Speech API для MVP

Основные экраны (MVP)
Экран	Основные функции
Login / Register	Авторизация, выбор уровня японского
Список диалогов	Фильтры по ситуации и уровню
Экран диалога	Текст сценария, кнопка записи, результат распознавания, оценка произношения
История обучения	Пройденные диалоги, оценки, возможность повторить
Admin панель	CRUD диалогов, управление пользователями, анализ данных
